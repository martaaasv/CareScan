# CareScan

CareScan is a healthcare management platform developed as part of my two Bachelor's Degree Final Projects in **Computer Science Engineering** and **Computer Engineering**.

The first project focused on the development of a complete web application for healthcare management, built with **Java, Spring Boot, Spring Security, Thymeleaf and MySQL**. The platform allows hospitals to manage patients, doctors, medical images and clinical information through different role-based interfaces.

In parallel, I developed a **Deep Learning model for brain tumor detection and classification from MRI images**, using **Python, TensorFlow/Keras and Computer Vision techniques**. The model was also complemented with **Grad-CAM** to provide visual explanations of the regions influencing each prediction.

The AI model was exposed through a **FastAPI REST API** and integrated into CareScan, allowing medical images uploaded through the web application to be automatically analyzed and the resulting predictions to be incorporated directly into the patient's clinical workflow.

Together, both projects form a complete system combining **backend development, web technologies, REST APIs, databases, cybersecurity and Artificial Intelligence**.

### Key features

* Patient and doctor management
* Role-based authentication and authorization
* Doctor–patient assignment
* Medical image upload and management
* Patient medical history
* Brain tumor classification using Deep Learning
* Grad-CAM visual explanations
* Integration between Spring Boot and a Python/FastAPI AI service
* Multilanguage support
* Statistics and administrative management
